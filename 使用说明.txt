《全童全星上课点名系统》使用说明

更新日期：2026-11-16
程序入口：version2.0.py（源码） / dist\dmxt.exe（单文件） /
          installer\全童全星上课点名系统_Setup.exe（标准安装程序）


一、程序简介
本程序是面向培训机构/学校的课堂点名工具，班级、学生、课表和签到记录都存放在
内置数据库中。支持班级切换、选择点名日期（可给往日补点名）、点击签到、课时调整、
签到保存、课表查看、签到记录导出、历史点名记录查询/修改/删除、学员积分的加减
与流水查询、积分商城商品兑换，以及多班级学员管理（学生全局唯一、一个学生可
同时在多个班）。班级与学员都支持从 Excel / CSV 批量导入。

【新版重要变化】程序已不再依赖外部 MySQL，改用内置 SQLite 数据库：
- 数据存成本地单文件 dmxt.db，装完就能用，无需安装 MySQL、无需配置连接；
- 数据文件自动放在「用户数据目录」：%APPDATA%\全童全星上课点名系统\
  （源码运行则放在项目根目录），卸载程序也不会丢数据；
- 第一次运行时，如果本机还有旧版 MySQL 的数据，会自动导入到新数据库，
  之后完全脱离 MySQL 运行。


二、运行环境
1. Windows 10 / 11
2. 标准安装版：直接双击 installer\全童全星上课点名系统_Setup.exe，一路下一步
   即可，无需装任何运行库
3. 绿色版：直接双击 dist\dmxt.exe（单文件，无需安装）
4. 源码运行需要 Python 3.10，依赖已全部内置（sqlite3 是标准库，无需额外安装）；
   仅在需要连接外部 MySQL 时才需 pip install pymysql dbutils


三、首次部署
1. 安装（推荐）
   双击 installer\全童全星上课点名系统_Setup.exe，选择安装目录（默认
   Program Files\全童全星上课点名系统），勾选是否创建桌面快捷方式，完成后
   桌面/开始菜单会出现「全童全星上课点名系统」图标。
   首次启动会自动创建数据库；若本机有旧版 MySQL 数据会自动迁移（见第一节）。

2. 免安装使用
   直接把 dist\dmxt.exe 复制到任意目录，双击即可。数据库同样自动创建在
   %APPDATA%\全童全星上课点名系统\。

3. 录入班级和学生
   - 班级、学生都能在程序的「管理员设置」里增删改（见第四章第 8 节）
   - 也可以直接编辑数据库文件 dmxt.db（用 SQLite 工具），或源码环境用 SQL：
     班级写 t_class，学生写 t_stu（stu_state 必填，1 正常），
     再往 t_stu_class 里插一行（stu_id + class_id）把学生放进班级
   - t_class.class_id：班级编号，界面下拉框显示的就是这个值
   - t_class.class_day：必须是“周一”到“周日”，否则该行不会出现在课表里
   - t_class.class_time、class_type：课表的时间段与课程内容
   - t_class.class_hour：该班默认课时数（点名页双击“课时数”可临时修改）
   - 学生全局唯一（同一姓名只建一条主档），班级归属看 t_stu_class 映射表，
     同一个学生可以同时映射到多个班级

4. （可选）切换到外部 MySQL
   默认用内置 SQLite，一般不需要改。如确需连接外部 MySQL，在数据目录下新建
   db_config.json（内容见 db_config.json.example），把 engine 设为 "mysql"，
   并填对 host/port/user/password/database；或用环境变量 DMXT_DB_ENGINE=mysql
   配合 DMXT_DB_HOST 等覆盖。

5. 启动
   安装版：桌面/开始菜单图标，或安装目录下的 dmxt.exe
   绿色版：双击 dist\dmxt.exe
   源码  ：python version2.0.py


四、日常使用
界面为「左侧深色导航 + 右侧内容区」：左侧切换页面（课堂点名、点名记录、
积分管理、积分商城、课程内容、暑假课程、寒假课程），左下角显示当前日期和数据库连接状态
（绿色=已连接，红色=未连接）；右侧每页顶部是标题，下面是统计卡片和内容卡片。

1. 课堂点名（默认页）
   - 统计卡片：顶部三张卡片分别是“本班人数 / 已签到 / 未签到”，随操作实时变化
   - 自动选班：打开页面时按“今天星期几 + 现在几点”自动定位班级。比如今天是周日，
     而课程内容里周日排了 08:20 / 10:30 / 14:10 / 16:00 四个班，10:35 打开就选中
     10:30 那个班；处在两次课之间就选接下来的一节；当天课都上完了就选最后一节；
     今天这个星期几没排课，则保留上次看过的班，不强行切换
   - 选班说明：班级下拉框下面那行小字写明为什么是现在这个班，例如
     “今天周日，已自动选中当前时段 · 14:10-15:40 · 无人机 · 正在上课”
   - 手动改过的班不会被抢回去：从下拉框自己选过班以后，切页、刷新都保持你的选择；
     想回到自动定位，点右上角“定位当前时段”
   - 选择班级：工具栏下拉框，显示的是 class_id
   - 选择点名日期（补点名）：工具栏第二行的「点名日期」默认是今天，可直接在框里
     输入 2026-11-13 / 2026/11/13 / 11-13；按回车、点到别处、或直接点「保存」
     都会生效（不必特意按回车），保存一律以框里显示的日期为准。
     也可以用「<」「>」前后翻一天、点「日历」在月历里挑一天、点「今天」一键回到当天。
     切换日期后，下方名单的签到状态、课时、三张统计卡和绿色说明小字会立刻
     按那一天的数据库记录刷新，不用重开软件。非今天时旁边会显示橙色「● 补点名中」
   - 补点名保存：选了往日日期后点「保存」，记录会写到那一天（日期按记录的
     创建时间判定），成功提示会写明写入的日期；「点名记录」页打开时会自动把
     查询范围放宽到这一天，按该日期可查，今天的记录不会被改动。
     切回「今天」就恢复常规点名。没点保存的勾选按日期各自留着，切走再切回不会串
   - 状态回显：程序启动、每次切回本页、切换点名日期、以及点“刷新数据”时都会重读
     数据库里「当前点名日期」的签到记录，那天已经点过名的学生直接显示“已签到”、
     行是浅绿底，课时也按当时保存的值显示；在“点名记录”页改/删了记录，
     回到这一页会立刻跟着变。班级下面的绿色小字会写明
     “数据库今日已有 N 条记录：已签到 X、未签到 Y · 最后录入 时:分”，
     补点名时则写明所选日期并提示“保存会写入这一天”。
     没手动挑日期时跨过零点会自动重读，不会带着昨天的勾
   - 签到：点击“操作”列的“✓ 签到”，该行变成浅绿底、按钮变为“✕ 撤销”；再点一次取消
   - 改课时：双击“课时数”单元格，输入数字后回车（Esc 取消）
   - 添加临时学生：点工具条“＋ 临时学生”，一次可填多个名字（换行/逗号/空格隔开）。
     临时学生只在本班、本次打开期间有效，以浅蓝底区分；可以和正式学生一样签到、
     改课时、保存（会写进签到记录）、导出；不会进入正式名单（管理员/学生管理页
     看不到）。双击弹窗里的临时学生名单可移除，切到别的班再切回来仍在
   - 刷新数据：重新从数据库读取班级、学生和当前点名日期的签到记录。库里被改过/
     删掉的记录以数据库为准（删掉的记录会变回“未签到”）；自己手动点过、
     还没保存的勾选会保留
   - 保存：把当前表格（含临时学生）按「当前点名日期」写入 t_sign。规则是
     “一个学生 + 一个班 + 一天”只留一条：已有记录就更新签到状态和课时，
     没有就新增；同一天反复点保存不会写出多条。同一个学生在别的班另有记录，
     两条互不影响（所以跨班上同一门课能各点一次名）
   - 导出签到记录：生成 TXT 保存在程序目录，文件名格式为
     签到记录_班级_年月日_时分秒.txt，文件内容会写明本次的点名日期
   - 数据库连不上时，页面顶部会出现红色提示条，程序不会闪退

2. 点名记录（历史）
   把常规班与暑假/寒假班的点名历史汇总到一张表里看；点名点错了、课时记错了，
   也可以在这一页直接改掉或删掉，不用回点名页重录。
   - 打开时默认只看「当天 + 当前班级」：日期起止都是课堂点名页当前选中的那一天
     （正常点名是今天，补点名时自动跟到那一天），班级下拉自动选中点名页当前的班，
     一打开就对上刚点完名的那批学生。点「重置」也回到这个默认视图
   - 想看更长时间用右上角快捷范围：「今天 / 近 7 天 / 近 30 天 / 近 90 天 / 全部」
     点一下连查询一起切换；班级下拉改选「全部班级」可看所有班
   - 筛选条件：
     · 时间范围：今天 / 近 7 天 / 近 30 天 / 近 90 天 / 全部 / 自定义，
       切一下自动填好起止日期；手改日期框会自动变成「自定义」
     · 日期：开始、结束都可留空（留空=不限），2026-11-13 / 2026/11/13 / 20261113
       三种写法都认；写错或开始晚于结束会弹提示，不会把列表清空
     · 来源：全部来源 / 常规班 / 暑假班 / 寒假班
     · 班级：点「选择班级…」会在按钮下方展开勾选面板（网页式多选下拉），
       可跨常规班 / 暑假班；点「完成」或面板外空白处即生效。
       班级多时右侧有滚动条（鼠标停在勾选项上也能滚），
       拖右下角的斜纹手柄可以改面板大小。
       一个都不勾就是全部班级，按钮旁会显示「已选 N 个班」；
       显示名带编号（如 01  周六 Python），同名班也分得清；
       切来源时不属于该来源的勾选会自动去掉
     · 学生：输入几个字模糊匹配姓名，回车即查
     · 只看签到 / 只看未签到：两个开关按钮，按下去分别只看来了的、没来的，
       方便课后核对谁缺课；再点一次取消。两个开关互斥，按下一个另一个自动弹起
       （不会出现「既只看签到又只看未签到」导致空列表）
   - 四个数字卡：记录条数 / 已签到 / 未签到 / 出勤率（已签到 ÷ 记录条数）
   - 「明细」和「按学生汇总」两个视图共用同一次查询结果，切换不重新查库：
     · 明细：日期、星期、班级、学生、课时、状态、点名时间、来源
     · 按学生汇总：每个「班级 + 学生」一行，出勤、缺勤、合计、出勤率，
       缺勤多的排前面，有缺勤的行浅黄底，一眼看到需要关注的学员
   - 导出 CSV：按当前视图导出当前筛选结果，文件名是 点名记录_年月日_时分秒.csv
     或 点名汇总_年月日_时分秒.csv；UTF-8 带 BOM，Excel 双击打开不乱码
     （明细导出还带上课时间和备注列）
   - 修改一条记录：在「明细」里双击那一行，或选中后点右上「修改记录」（右键菜单
     里也有）。弹窗里能改签到状态、课时、备注；保存后四个数字卡和「共 X 条」
     立即刷新，光标还停在原来那行，连着改几条不用重新找
   - 删除记录：选中后点「删除记录」，或直接按 Delete 键，右键菜单里同样有；
     按住 Ctrl 可以多选批量删，确认框会把要删的每一条列出来
   - 改和删只在「明细」视图开放：汇总视图里一行对应好几条记录，没法确定改哪条
   - 日期和班级不提供修改：常规班的日期由点名保存时间决定，假期班的日期挂在
     「课次」上（一个班共用一条课次），改了会牵连同班其他学员。要换日期请到
     课堂点名页把「点名日期」切到正确那天重新录一条，再把错的那条删掉
   - 改了当天（或课堂点名页当前选择的日期）的常规班记录后回到点名页，
     勾选会以数据库为准重新显示
   - 常规班的日期取「点保存那天」，假期班的日期取那次课的日期；同一天同一人
     有两条记录就分成两行，不会合并
   - 一次最多读 5000 条，到上限时右上角会提示缩小日期范围

3. 积分管理（侧边栏「★ 积分管理」）
   给学员加/减积分，每次变动都生成一条带备注的流水，随时可查、可导出。
   - 上方四个数字卡：学员人数 / 积分总计 / 累计获得 / 累计扣减（看「今天」时
     标题自动变成 今日积分 / 今日获得 / 今日扣减），跟着班级、姓名和积分范围一起变
   - 「积分范围」在下方「积分流水」工具条上，默认「今天」，同时管上方学员积分
     与下方流水：选「全部」时学员显示累计总积分，选「今天」时只显示当天加减分
     的合计（净额），「加分」「扣分」两列也只算当天；名次、统计卡、表头文字
     同步跟着变。另有「近 7 天」「近 30 天」和「自定义」（直接改起/止日期就
     自动切成自定义）。页头右侧的「全部」「今天」是同样的快捷入口
   - 按班级分类：左上角「班级」下拉选「全部班级」或某个班，学员列表只列这个班的人；
     「姓名」框输入几个字模糊筛选；「重置」一次清空所有筛选
   - 学员列表按「当前积分」从高到低排名，第一列是名次；积分相同的学生
     并列同名次（例如 1、2、2、4），同分时按班级、姓名排，顺序不会乱跳。
     切班级或输姓名筛选后，名次会按当前筛选结果重新从 1 开始算；
     每次加减分后也会立即重新排名
   - 学员列表显示：排名、班级、姓名、积分（所选范围内的净变动，「全部」时就是
     累计总积分）、加分（范围内累计获得）、扣分（范围内累计扣减）；看今天时表头
     写成「今日积分 / 今日加分 / 今日扣分」标出口径。负积分整行标浅红，
     行数多时右侧有滚动条
   - 列表高度可以用鼠标调：学员列表和下方「积分流水」之间有一条写着
     「⇕ 拖动调整高度（双击复原）」的分隔线，按住它上下拖即可改变学员列表
     的高度，流水区会自动补上剩下的空间。默认高度一次能看到 10 名学生；
     想多看流水就往上拖，想多看学生就往下拖；双击分隔线可恢复默认高度。
     拖出来的高度会记住（存到用户数据目录的 ui_config.json），下次打开或
     切走再回来都保持；窗口太小时会自动临时收窄，窗口变大又自动恢复
   - 加/减分：点左边选中一名学生 → 右边点快捷分值（+1/+3/+5/+10 或
     -1/-3/-5/-10），也可以直接在「分值」框手输（正数加分、负数减分）；
     填「备注」（如「课堂积极回答问题」「迟到」），再点「确认调整」。
     按钮旁边会先显示「本次 +3 分 → 调整后 11 分」，确认前能核对
   - 自定义快捷键（页头右侧「快捷键设置」）：默认 5 行、最多可加到 12 行
     （左下「＋ 添加一行」），每行填「快捷键 + 分值 + 备注」，整行留空就不用
     · 按键点「录制」后直接按，或手输 F1、Ctrl+1、a；支持 F1~F12、字母/数字，
       以及 Ctrl / Alt / Shift 组合；Ctrl+A、Alt+F4 等系统组合不许占用
     · 分值正加负减（±9999），备注会原样写进这一笔积分流水，可以留空
     · 用法：左边选中一名学生，按一下快捷键就立即记一笔，列表、名次、统计卡
       和流水同步刷新，选中状态不变；扣成负分时同样会先弹一次确认
     · 已配置的按键和分值会列在右侧「调整积分」区，不用背；光标停在输入框里
       时字母/数字快捷键不触发（F 键和 Ctrl / Alt 组合键仍可用）
     · 设置存在数据目录 points_shortcuts.json，换电脑一起拷走；重复按键、
       缺分值、备注超 200 字都会拦下不让保存
   - 备注最多 200 字、可留空；单次分值限 ±9999；扣到负分会弹一次确认。
     提交后立即刷新学员积分、四个数字卡和下方流水，选中状态保持不变，
     可以连着给同一个学生记几笔
   - 积分余额不是单独存的字段，而是这个学生所有流水加起来的结果：
     改名、转班都不影响（按学生编号记账），学生被删后历史流水仍查得到
   - 加减分始终按「累计总积分」记账，不受上面的范围影响：即使正在看「今天」，
     选中学生时右侧写的「当前 X 分」仍是累计余额，括号里另标本期的分值；
     扣成负分的判断和「调整后 X 分」预览也都按累计余额算，不会把历史积分抹掉
   - 下方「积分流水」：时间、班级、学生、变动、变动后的余额、备注；
     加分行浅绿、减分行浅红，最新一笔在最上面
     · 「从 / 至」日期框打开就填好当天（默认只看今天的流水），留空=不限；
       格式 YYYY-MM-DD，写错会提示「日期格式应为 YYYY-MM-DD」
     · 它和「积分范围」下拉两处联动：任一边改动，上方学员积分、排名、统计卡
       与下方流水一起按新区间重算；手动改日期会把范围自动切成「自定义」
     · 还可按姓名关键字筛选；勾「只看选中学生」就只看左边点的那个人；
       点「查询」立即刷新
     · 右上角「导出流水」把当前筛选结果存成 积分流水_年月日_时分秒.csv
       （UTF-8 带 BOM，Excel 打开不乱码），文件也在用户数据目录
     · 一次最多读 5000 条，到上限会提示缩小日期范围
   - 流水只追加，不提供修改和删除：记错了就再记一笔反向分值并写明原因，
     这样每笔都留痕、账目能对得上
   - 积分数据也在 dmxt.db 里，跟班级/学生/签到一起被「备份与恢复」覆盖；
     恢复没有积分表的旧备份时会自动补建空表，不会报错

4. 积分商城（侧边栏「◆ 积分商城」）
   用积分兑换小奖品，兑换时自动扣分并留下记录。
   - 先到「积分管理」给学生加分；商城左侧学员列表按积分降序显示当前余额，
     可按班级、姓名筛选
   - 商品管理：中间商品列表下方有「＋ 新增 / 编辑 / 下架 / 删除」
     · 新增时填：名称、所需积分（正整数）、库存（-1 表示不限量）、说明
     · 「下架」的商品整行变灰、不能兑换，再点一次「上架」可恢复；
       已经有兑换记录的商品不能删除，只能下架，这样历史记录始终有出处
   - 兑换：左边点选学员 → 中间点选商品 → 右边填数量（1~99）和备注 →
     核对「需 X 分  →  兑换后剩 Y 分」→ 点「确认兑换」并二次确认
     · 积分不够、库存不足、商品已下架都会被拦下，不允许透支
     · 兑换成功会同时做三件事（同一次事务，失败全部回滚）：扣库存、
       写一笔负积分流水（备注含商品名与数量）、生成一条兑换记录。
       所以「积分管理」页的余额、流水、统计卡会立刻同步，不用两边对账
     · 兑换记录和积分流水一样只追加，不提供改和删；发错货或退换请到
       「积分管理」补一笔正分，备注写明原因即可
   - 下方「兑换记录」：时间、班级、学员、商品、数量、消耗积分、备注；
     可按日期区间（YYYY-MM-DD，留空=不限）筛选、勾「只看选中学员」，
     页头「导出兑换记录」存成 积分兑换记录_年月日_时分秒.csv
     （UTF-8 带 BOM，Excel 不乱码），文件在用户数据目录
   - 上方三栏和下方记录之间有一条「⇕ 拖动调整高度」分隔线，
     拖动可改三栏高度，双击恢复默认，拖过的高度会记住（ui_config.json）
   - 商品、兑换记录、积分流水都在 dmxt.db 里，跟其它数据一起被备份覆盖；
     恢复没有商城表的旧备份时会自动补建空表，不会报错

5. 课程内容
   按 t_class.class_day 分组的周课表，顶部显示上课天数与课程节次；
   点击某行可高亮，再点一次取消

6. 暑假课程 / 寒假课程
   假期班的上课日期不固定（可能连上五天，也可能隔天），所以和常规班分开管：
   班级、学员都由老师自己定，点名按「课次」走——一次课一条记录，互不覆盖。
   - 先选班级（「班级」下拉），再选课次（「课次」下拉，显示第几次、日期、时间段）
   - 课次默认选中「今天」那次；今天没课就选最近的一次，补录和提前点名都顺手
   - 页面上三个数字：本班学员 / 课次总数 / 本次已签到；下面一行是这次课的时间、
     内容和签到进度
   - 点名：点某行「操作」列的「✓ 签到」，再点变「✕ 撤销」。点一下立即写库，
     切课次、切页、改外观都不会丢，不需要另点保存
   - 改课时：双击「课时数」单元格，输入后回车；默认取班级的「每次课课时」
   - 「全部签到」一键把本班学员全标为已签到；「导出记录」按当前课次生成 TXT，
     含日期、时间段、内容、已到/未到名单
   - 右上角四个入口：「＋ 新建班级」「学员管理」「课次管理」「刷新」

   6.1 班级 / 学员 / 课次（设置窗口上方三段）
   - 班级：填名称（同一次假期内不重名）、课程内容、每次课课时、开班/结班日期。
     日期可以只写 7-6，程序自动补当前年份
   - 学员：先选班级，再逐个添加（姓名必填，手机号、备注可空）；
     也可以点「从常规班导入」，选一个常规班把在读学生一次复制过来，重名自动跳过
   - 课次：先选班级，点「＋ 新增课次」填日期、时间段（如 09:00-12:00）和本次内容；
     同一天同一时间段不允许重复；列表「出勤」列显示 已签到 / 本班人数
   - 「去点名 →」把主界面切到所选的这次课
   - 班级和学员都是软删除：删掉后记录仍在库里，勾选「显示已删除」可以恢复；
     删除课次会连同这次课的签到记录一起删除，确认框里会写明会丢多少条
   - 假期班的学员和常规班名单互不影响，两边的点名记录也各存各的

7. 外观设置（左下角「◐ 外观设置」）
   - 预设配色：浅灰 / 雾蓝 / 暖砂 / 青岚 / 暮紫 / 墨夜 六套，点色卡即时预览
   - 自定义图片：可把 JPG/PNG/BMP/WebP 设成内容区背景，图片按“铺满”方式居中裁剪，
     不会拉伸变形；白色卡片浮在图片上方，卡片间隙透出背景
   - 图片遮罩：无 / 轻 / 中 / 重，图片太花时加一层遮罩，保证标题和表格不刺眼。
     遮罩颜色会按图片明暗自动选择（亮图压白、暗图压黑），标题字色也跟着切换
   - 「应用」写入 ui_config.json 并长期生效，「取消」回到打开前的样子
   - 选择图片不需要额外依赖：JPG 走 Windows 自带的 GDI+ 解码，打包版同样可用

   8. 管理员设置（左下角「⚙ 管理员设置」）
   窗口上方有「班级管理 / 学生管理」两个页签，改动都会立即同步到点名页和课程页，
   不用手动刷新。右侧「⇩ Excel 导入」可以批量导入班级和学员（见 8.3）。
   - 进入需要口令。第一次使用的默认口令是 admin，进去后建议点「修改口令」改掉
   - 口令以 PBKDF2-SHA256 加盐哈希保存在程序目录的 admin.json，不存明文。
     忘记口令可以删掉这个文件，口令会恢复成默认的 admin
   - 数据库连不上时，列表区会显示错误原因，增删改按钮自动禁用

   8.1 班级管理
   - 列表列出全部班级：编号、名称、课程、星期、上课时间、默认课时、学生人数
   - 新增班级：填班级编号（必填，下拉框显示的就是它）、星期（必选）、默认课时（必填），
     其余可选。编号不能重复、不能含空格
   - 编辑班级：双击一行，或选中后点「编辑」。改「班级编号」时，该班的学生和签到记录
     会在同一个事务里一起迁移到新编号，不会变成没人管的数据
   - 删除班级：选中后点「删除」。按约定**只删班级、不删学生**——该班的学生映射
     一并清除，学生主档和签到记录仍保留，但不再属于任何班级。若班里还有学生，
     确认框里会显示人数
   - 管理该班学生：选中一个班后点「管理该班学生 →」，直接跳到学生页并锁定这个班，
     不用切页后再找一遍；学生页左上角的「← 班级」可以回到班级列表

   8.2 学生管理
   学生在数据里是全局唯一的：一名学生只有一条记录（按姓名判唯一），姓名、课时、
   手机号、状态都是学生本人的资料；班级归属通过映射表保存，一个学生可以同时在
   多个班级。
   - 左上角下拉有两个视图：
     · 「◎ 全部学生」：列出所有学生主档，多一列「所在班级」（多个班用、分隔，
       还没加入任何班的显示「未分班」）
     · 选某个班：只列该班学员，即点名页看到的名单
   - 筛选姓名：输入几个字即时过滤，清空恢复全部
   - 新增学生（只在「全部学生」视图）：填姓名（必填，全库不能重名）、剩余课时
     （默认 2.5）、手机号（可留空）、状态。新增的学生只是建档，还不属于任何班，
     保存后提示里会写下一步怎么分班
   - 新增学员（选中某个班时）：弹出选择框，**只能从现有学生里挑**，可一次选多人：
     点某一行就打勾/取消（勾选列显示 ☑），点表头「全选」或右侧「全选 / 清空」
     可批量操作；也支持 Ctrl / Shift 连选、Ctrl+A 全选、空格切换。
     支持姓名筛选，筛选后已勾的人不会被清掉，底部会显示「已勾选 N 名」。
     选择框按当前屏幕分辨率自动定大小（小屏会少显示几行），四边都能用鼠标
     拖动缩放，拖小了底部按钮也不会被挤掉。想凭空新建学生请回「全部学生」视图
   - 移出本班（选中某个班时）：把选中学生从当前班移走。只解除班级归属，学生记录、
     其他班级的归属和签到记录都保留，之后随时能再加回来
   - 编辑学生：双击一行，或选中后点「编辑」。改名会把该学生在**全部班级**的历史
     签到记录一起改名；转班不在这里做——用「新增学员 / 移出本班」组合即可
   - 删除学生：选中后点「删除」。**删除不是真的从库里删掉**，只是把有效标志
     stu_state 置 0，学生从所有班级名单里消失，记录和签到都还在，随时可以找回来
     · 列表默认不显示已删除的学生；勾选右下角「显示已删除」就会列出来（灰字、排在最后）
     · 选中一条已删除的学生时，右上角「删除」会变成绿色「恢复」，点它就能重新启用，
       状态回到「正常」，之前所在的班级也一起恢复
     · 学生有签到记录（全部班级合计）时会多问一句：「只删除学生」保留签到历史，
       「连签到一起清除」把该生的签到记录一并清掉——签到记录清掉就真的没了
     · 已删除的学生不会出现在点名页，也不计入班级人数
   - 学生全局不允许重名（同名视为同一个学生）；如果同名是一条已删除的记录，
     新增时会提示先把它恢复，不会插出第二条
   - 停课/结课的学生仍显示在点名页，但文字变淡，不容易和正常学生搞混

   8.3 Excel 批量导入（班级 / 学员）
   入口：管理员设置右上角「⇩ Excel 导入」，或班级管理页操作行的「导入 Excel」。
   一个窗口两种模式，流程一样：下载模板 → 填好 → 选择文件 → 看预览 → 开始导入。
   - 导入班级：必填「班级编号」「星期」，可选「班级名称、课程类型、上课时间、
     默认课时」。星期写 周六 / 星期六 / 周6 / 6 都认；课时留空按 2.5
   - 导入学员：必填「姓名」，可选「剩余课时、手机号、状态、班级」。「班级」列
     可写多个班（用、或空格分隔，如 01、02），导入时自动建立班级归属；班级必须
     先在「班级管理」里存在，否则该行会标红不导入
   - 首行必须是列名，列的顺序随意，多出来的列会被忽略；列名还能写成「班级号」
     「学生姓名」「所在班级」这类常见写法
   - 预览逐行列出「新增 / 更新 / 已有 / 跳过 / 错误」和原因，标红的行不会导入；
     改正后重新选同一个文件即可。导入不会删除任何已有数据
   - 已有数据默认不覆盖：班级编号或学生姓名已存在时只跳过（学生若填了新班级，
     会把缺的班级补上，不会重复建档）。想用表格内容覆盖，勾选「已存在时更新资料」
   - 支持 .xlsx / .xlsm，以及 .csv（UTF-8、GBK 都能读）；老式 .xls（97-2003）
     读不了，请用 Excel 打开后「另存为」.xlsx 再导入
   - 模板第二个工作表「填写说明」里写了每列怎么填，可直接对照

   老版本升级说明：旧数据里「同一个学生在多个班各有一行」的记录，首次打开会
   自动合并成一条学生主档 + 多条班级映射（积分流水一并归并，签到记录按姓名
   保持不变），无需任何手工处理。


五、数据表说明
t_class  班级与课表
  class_id    班级编号（主键）
  class_name  班级名称
  class_day   星期（周一..周日）
  class_time  上课时间段
  class_type  课程内容
  class_hour  默认课时数
  class_val   预留字段

t_stu    学生主档（一名学生全库一条）
  stu_id        学生编号（主键，自增）
  stu_name      姓名（全局唯一）
  stu_class_id  历史遗留列，仅作参考；班级归属以 t_stu_class 为准
  stu_hour      剩余课时
  phone         联系电话
  stu_state     有效标志：0 已删除（记录保留、可恢复），1 正常，2 停课，3 结课

t_stu_class  学生-班级映射（一个学生可映射多个班级）
  map_id        映射编号（主键，自增）
  stu_id        学生编号（t_stu.stu_id）
  class_id      班级编号（t_class.class_id）
  create_time   加入时间
  唯一约束：同一名学生在同一个班只有一条映射

t_sign   签到记录
  dm_id         记录编号（主键，自增）
  stu_name      学生姓名
  stu_class_id  班级编号
  sign_hour     本次课时数
  sign_state    已签到 / 未签到
  sign_time     保存时间文本
  create_time   创建时间（默认当前时间，用于判断“当天”）
  update_time   更新时间（自动维护）

t_point_record   积分流水（首次打开「积分管理」时自动建表）
  record_id      流水编号（主键，自增）
  stu_id         学生编号（积分跟着它走，改名/转班都不丢）
  stu_name       当时的姓名快照（学生删了历史仍可读）
  class_id       当时的班级快照
  delta          变动分值：正数加分、负数减分，不允许 0
  balance_after  本笔之后的余额（冗余字段，便于对账）
  note           备注 / 原因（最多 200 字，可空）
  create_time    发生时间 YYYY-MM-DD HH:MM:SS
  说明：当前积分 = 该学生所有 delta 之和，不单独存字段；流水只追加不改删。
        积分商城兑换成功时也会在这里写一笔负数流水（备注含商品名 ×数量）。

t_goods          积分商城商品（首次打开「积分商城」时自动建表）
  goods_id       商品编号（主键，自增）
  goods_name     商品名称
  cost           兑换所需积分（单件，正整数）
  stock          剩余库存；-1 表示不限量
  note           商品说明（可空）
  state          1 上架 / 0 下架（下架后不能兑换）
  create_time    创建时间
  说明：已有兑换记录的商品不能删除，只能下架，历史记录才有出处。

t_exchange       积分兑换记录（只追加，不提供改和删）
  exchange_id    记录编号（主键，自增）
  stu_id         学生编号
  stu_name       当时姓名快照
  class_id       当时班级快照
  goods_id       商品编号
  goods_name     商品名快照（商品之后改名/删除都不影响历史）
  cost           单件积分快照
  qty            兑换数量
  total_cost     本次共扣积分 = cost × qty
  note           兑换备注（可空）
  create_time    兑换时间 YYYY-MM-DD HH:MM:SS
  说明：兑换与扣分流水、扣库存在同一次事务里完成，失败整体回滚。

t_season_class   假期班级（暑假/寒假）
  sclass_id     班级编号（主键，自增）
  season        summer 暑假 / winter 寒假
  class_name    班级名称（老师自定义）
  class_type    课程内容
  class_hour    每次课默认课时
  start_date    开班日期（可空）
  end_date      结班日期（可空）
  state         有效标志：0 已删除（可恢复），1 有效

t_season_stu     假期学员（直接挂在假期班级下）
  sstu_id       学员编号（主键，自增）
  sclass_id     所属假期班级
  stu_name      姓名（同班不重名）
  phone         手机号（可空）
  note          备注（可空，如“需午餐”）
  state         有效标志：0 已删除（可恢复），1 有效

t_season_lesson  假期课次（一条 = 某天某个时间段的一次课）
  lesson_id     课次编号（主键，自增）
  sclass_id     所属假期班级
  lesson_date   上课日期
  lesson_time   时间段，如 09:00-12:00
  topic         本次内容
  note          备注

t_season_sign    假期签到（按课次记，一次课一份）
  sign_id       记录编号（主键，自增）
  lesson_id     所属课次
  sclass_id     所属假期班级
  sstu_id       学员编号
  stu_name      姓名（冗余一份，导出时直接可读）
  sign_hour     本次课计课时
  sign_state    1 已签到 / 0 未签到
  sign_time     保存时间文本
  （lesson_id + sstu_id 唯一：同一次课同一学员只保留一行，重复点名就是更新）


六、常见问题
1. 启动后提示“数据库不可用”
   - 新版用内置 SQLite，一般不会出现；如果出现，多半是数据目录不可写。
     检查 %APPDATA%\全童全星上课点名系统\ 是否存在、是否被占用或只读
   - 若已切换到外部 MySQL（db_config.json 里 engine=mysql），则确认 MySQL 服务
     已启动，并核对地址、端口、账号、密码、库名
   - 详细错误见数据目录下的 dmxt_error.log

2. 下拉框没有班级、名单为空
   - 还没有录入班级/学生，或 stu_class_id 与 class_id 不一致

3. 保存失败
   - 查看数据目录下的 dmxt_error.log；确认 dmxt.db 所在目录可写

4. 导出的 TXT / CSV 找不到
   - 文件在用户数据目录 %APPDATA%\全童全星上课点名系统\（源码运行则在项目根）
   - 导出成功的弹窗里会显示完整路径
   - 点名记录 CSV、签到记录 TXT、假期签到 TXT、积分流水 CSV 都放在这个目录

5. 打开点名页默认班级不对
   默认班级是按 t_class 的 class_day（周一~周日）与 class_time（如 08.20-10.20）
   算出来的。如果自动选错了，先到「课程内容」页核对这两列：
   - 星期写成了“星期日 / 礼拜日 / 周日（前后有空格）”——必须严格是
     周一 周二 周三 周四 周五 周六 周日
   - 上课时间格式不规范（如 cc、116.10-18.10）——程序会尽量猜，猜不出就把该班
     排到当天最后；时间支持 08.20-10.20 / 8:20-10:20 / 08：20~10：20 等写法
   临时想换班，直接在下拉框里选；想恢复自动定位，点右上角“定位当前时段”

6. 课程内容是空的
   - 检查 t_class.class_day 是否严格为“周一”到“周日”

7. 管理员设置打不开 / 忘记口令
   - 默认口令是 admin；改过以后忘了，删除数据目录下的 admin.json，口令恢复默认
   - 提示“口令不正确”说明输入有误，注意大小写

8. 学生改名、转班后签到记录怎么算
   - 改名：该班历史签到里的姓名会一起改成新名字，保证记录能和学生对上
   - 转班：历史签到留在原班级，新班级从零开始统计，不会把旧账带过去

9. 学生删错了怎么找回
   - 删除只是把 stu_state 置 0，记录还在表里：勾选学生页右下角「显示已删除」，
     选中该学生后点绿色「恢复」即可，签到记录原样都在
   - 恢复后状态统一回到「正常」；原来是停课/结课的，重新改一下状态即可
   - 想彻底清理：直接对 t_stu 里 stu_state = '0' 的行做 DELETE（界面上不提供硬删除）

10. 假期课程里看不到班级 / 课次
   - 先确认顶部「班级」下拉里选中的是哪个班；课次是逐个加的，新班还没有课次
   - 点右上「课次管理」→ 选班级 → 「＋ 新增课次」，加上当天的日期即可
   - 页面第一次打开时会自动建 t_season_* 四张表，如果报“建表失败”，
     检查数据库账号是否有 CREATE 权限

11. 假期班的学员要重新录一遍吗
   - 不用。在「学员管理」里点「从常规班导入」，选一个常规班即可整班复制，重名跳过
   - 也可以只挑几个学生手工新增；导入后和原班没有任何绑定，改这边不影响常规班

12. 删掉一次课，签到记录还能找回吗
   - 不能。课次是排课记录，删除时会连同这次课的签到一起删掉，确认框里会写明条数
   - 学员和班级是软删除，只有它们可以恢复

13. exe 和源码行为不一致
   - dist\dmxt.exe 需要重新打包才会包含最新代码：
     .\.venv\Scripts\python.exe -m PyInstaller dmxt.spec
   - 打包时 assets\app.ico 会嵌进 exe 当文件图标，同时打进包内给标题栏/任务栏用；
     exe 换图标要重新打包，源码运行时则直接读 assets\ 下的文件

14. 想换程序图标
   - 把新图做成 256×256 的 PNG（背景透明更好看），覆盖 assets\logo.png，
     再重新生成 assets\app.ico（用同名的多尺寸 ico 更清晰）
   - 只换 assets\ 里的文件不重新打包，exe 的图标不会变（.ico 是编译进 exe 资源的）

15. 点名记录页看不到某次点名
   - 默认只看「当天 + 当前班级」：点右上「全部」看全部时间，再把班级下拉改成
     「全部班级」就能看到所有班的历史；只想看某一天也可用「今天」或手填起止日期
   - 常规班的记录是点「保存」时才写进 t_sign 的，只点了签到没保存不会有记录
   - 日期显示「未知」的是很久以前没有写入时间的老数据，统一按未签到算
   - 记录确实在库里却看不见，先点「刷新」；还是不行就看是不是被「只看签到 /
     只看未签到」或班级筛选挡住了

16. 打开软件后有的学生已经是“已签到”
   - 这是正常的：程序启动会读数据库里「当前点名日期」（默认今天）的签到记录
     并原样显示，不是别人改过你的表；工具栏第二行能看到当前选的是哪一天
   - 班级下面的绿色小字会写明“数据库今日已有 N 条记录 … 最后录入 时:分”，
     补点名时则写明所选日期，可据此判断是不是那天已经点过名；
     想重新核对可以点「刷新数据」再读一遍
   - 同一个学生、同一个班、同一天只会有一条记录；如果发现今天有多条重复（老版本
     留下的），点一次「保存」会自动合并成一条

17. 同一个学生要在两个班上课
   - 把这个学生映射到两个班：学生管理里选中班级点「＋ 新增学员」把现有学生加
     进来即可（学生本身只有一条记录，积分、课时、手机号两个班共用）
   - 点名按班分别点、分别保存；同一个班、同一天记两次是不允许的（再点保存只会
     更新那一条），这是有意的规则
   - 以后不想在某班上了，选中后点「移出本班」，历史签到和积分都保留

18. 点名点错了 / 课时记错了
   - 到「点名记录」页找到那一条（双击即可修改），改签到状态、课时或备注都行；
     真的录错了（比如多了一条）就选中后删掉
   - 改了/删了当前点名日期的记录，回「课堂点名」时会立刻以数据库为准，不会再显示改动前的
     勾选；点「刷新数据」也以数据库为准。只有「自己手动点了但还没点保存」的勾选
     会保留，避免把没保存的点名冲掉
   - 注意：删掉记录后如果又回「课堂点名」点「保存」，程序会把当前班所有学生
     （包括显示“未签到”的）重新写一遍记录，看起来像“删了又回来”。这是保存的
     正常规则，删完不用再点保存
   - 删掉之后想找回，只能靠「备份与恢复」里的旧备份，所以大改动前建议先点一下
     「立即备份」

19. 积分记错了 / 想删掉一笔
   - 流水是有意做成只追加的，不提供改和删，这样每一笔都留痕、能对账
   - 加多了就再记一笔 -3 分，备注写「冲正：撤销 11 月 13 日误加的 3 分」；
     少加了就补一笔正分，余额会自然算对
   - 想核对某一笔前后的账：勾「只看选中学生」，再用日期区间把那个人的流水筛出来，
     或直接「导出流水」用 Excel 看

20. 积分页看不到某个学生 / 换班后积分没了
   - 先看左上角「班级」是不是停在某个班，切回「全部班级」；「姓名」框里
     留过的关键字也会过滤列表，点「重置」一次清空
   - 积分按学生编号累计，改名、转班都不会清零。如果学生是在管理员设置里被
     「删除」了（软删除），名单里不再出现，但历史流水仍在，导出的 CSV 能查到
   - 恢复过旧备份的话，积分会回到那个备份时点的状态（备份是整库复制）

21. 积分页的学员列表太矮 / 看不到几个学生
   - 默认一次能看 10 名学生。把两张卡片之间那条「⇕ 拖动调整高度」分隔线
     往下拖，学员列表变高、流水区变矮；往上拖则相反
   - 双击分隔线恢复默认；拖过的高度会记住，重开软件也保持
   - 窗口拉得太小时，软件会先保证下方流水区还能看见而临时收窄列表，
     把窗口最大化或拉高后会自动恢复到你设定的高度

22. 积分页的名次是怎么算的 / 为什么跳号
   - 列表按当前积分（所有流水加起来的余额）降序排，第一列就是名次
   - 积分相同算并列，所以会出现 1、2、2、4 这样跳过 3 的情况，这是正常排名
   - 名次只针对当前筛选出来的学生：切到某个班、或输入姓名搜索后，
     会按剩下这些人重新从第 1 名排起；点「重置」回到全部班级就是总排名
   - 刚加完分的学生如果超过别人，会立刻排到前面，选中状态不会丢

23. 积分兑换错了 / 想把分退给学生
   - 兑换记录和积分流水一样是只追加的，不提供改和删，这样每笔都能对账
   - 到「积分管理」选中这个学生，补一笔同等分值的正分，
     备注写「冲正：撤销 X 月 X 日兑换的《商品名》」，余额就回来了
   - 库存不会自动加回去，需要到「积分商城」编辑该商品把库存改回来

24. 积分商城里看不到某个学生 / 点确认兑换没反应
   - 先看左上角「班级」是否停在某个班、「姓名」框是否留了关键字，点「重置」清空
   - 学生是在「管理员设置」里被软删除的话不会出现在名单里，
     其历史积分和兑换记录仍保留，导出 CSV 能查到
   - 兑换是「左边选学员 + 中间选商品」两步都要点；右侧会显示
     「需 X 分 → 兑换后剩 Y 分」，红色提示就是被拦下的原因
     （积分不足 / 库存不足 / 商品已下架 / 数量不在 1~99）
   - 商品列表默认显示上架商品，下架的会变灰列在后面，也能选中后点「上架」恢复

25. 怎么给以前的课补点名 / 切了日期状态没变
   - 课堂点名页工具栏第二行「点名日期」：点「日历」在月历里挑一天，或直接
     输入日期后回车，也可以用「<」「>」前后翻一天。切换后表格、课时、
     统计卡和绿色说明小字会立刻按那一天的数据库记录刷新
   - 那天本来没点过名就全部显示「未签到」，这是正常的；勾选后点「保存」
     会写成那一天的记录，在「点名记录」页按该日期可查，今天的记录不受影响
   - 选了往日日期后页面不会自动跨天跳回今天（避免打断补点名），
     点「今天」即可回到常规点名，之后才恢复跨天自动跟随
   - 框里手输日期后直接点「保存」也按框里的日期写库；日期写得不合法会弹提示并
     停止保存，不会偷偷写到今天。补点名后打开「点名记录」页，默认就显示所选
     那一天 + 当前班级的记录，不用再手动调日期；想看全部点「全部」
   - 状态没按预期变化时先点「刷新数据」；在「点名记录」页改/删了那天的记录，
     回到点名页也会同步；没保存的勾选按日期分别保留，不会串到另一天

26. 「新增学员」选择框太大 / 想一次加好几个人
   - 选择框按屏幕可用区域自动定初始大小，不会顶出屏幕；小屏会自动少显示几行，
     想看更多学生直接拖窗口边框拉高拉宽，表格会跟着伸缩
   - 一次加多人：点行打勾（不用按 Ctrl），或点表头「全选」/ 右侧「全选」按钮，
     最后点「加入本班」；底部「已勾选 N 名」可核对人数
   - 先用「筛选」缩小范围再全选，只会勾上筛选出来的学生；筛选期间勾选不丢

27. Excel 导入后没变化 / 提示某行「错误」
   - 先看预览里的「说明」列：标红行不会写库，改完表格重新选文件即可
   - 「没找到表头」：首行必须是列名，且至少有「班级编号」（班级表）或「姓名」
     （学员表）；表头前面不要留空行
   - 「班级 09 不存在」：学员表里的班级得先在「班级管理」建好，或先导一遍班级表
   - 「编号已存在」是正常提示：默认不覆盖，勾选「已存在时更新资料」才会按表格改
   - 从系统导出的 .xls 导不进来：用 Excel 打开后「另存为」.xlsx，或另存为 .csv
   - 导入只是新增/更新，不会删数据；导错了到列表里手工删即可

28. 积分页打开后数字变小了 / 只想看今天的积分
   - 「积分范围」默认「今天」：学员列表、名次、统计卡和下方流水都只统计当天
     的加减分，所以刚打开时数字比累计总积分小是正常的
   - 想看累计总积分：在下方「积分流水」工具条把「积分范围」切成「全部」，
     或直接点页头右侧的「全部」；日期框会清空，表头恢复成「积分/加分/扣分」
   - 加减分不会受影响：无论正在看哪个范围，选中学生时右侧写的「当前 X 分」
     都是累计余额，写库也按累计余额记，不会因为切到「今天」把历史积分抹掉
   - 积分流水的「从 / 至」日期框默认填的是当天，想看历史把起止日期改掉
     （会自动切成「自定义」）或把范围切到「全部」

29. 快捷键按了没反应 / 想换掉某个快捷键
   - 先确认在「积分管理」页，且左边已经点选了一名学生；没选人只会在右侧提示，
     不会记分。快捷键在其它页面本来就不生效
   - 光标停在「分值」「备注」「姓名」这类输入框里时，字母 / 数字快捷键会让位给
     打字；点一下学员列表，或改用 F 键 / Ctrl、Alt 组合键即可
   - 按键被系统或输入框占用（Ctrl+A、Alt+F4 等）在设置时就会被拦下；重复按键、
     分值没填或填了 0、备注超 200 字也不让保存
   - 改按键 / 分值 / 备注：点页头「快捷键设置」，改完点「保存」立即生效；
     某一行不想要了点「清空」，全部留白就等于关掉所有快捷键。
     5 行不够用点左下「＋ 添加一行」，最多 12 行；加过又清空的行不会写进配置
   - 换电脑后快捷键没了：把数据目录里的 points_shortcuts.json 一起复制过去


七、备份与迁移
新版数据都在一个文件里，备份/换电脑非常方便：
- 一键备份/恢复：左下角「▣ 备份与恢复」按钮，点「立即备份」即可把当前数据
  存成带时间戳的副本（在数据目录 backups\ 下）；备份列表里双击某条即可恢复，
  恢复前会自动把当前数据另存一份，不会直接丢弃；右键可删除旧备份。
- 手工备份：直接复制 %APPDATA%\全童全星上课点名系统\dmxt.db（连同 admin.json、
  ui_config.json、points_shortcuts.json 一起复制可保留口令、外观和积分快捷键设置）
- 恢复/换电脑：把 dmxt.db 放回目标机器的 %APPDATA%\全童全星上课点名系统\ 即可
- 旧版 MySQL 用户升级：新版首次启动会自动把旧 MySQL 数据导入 SQLite，无需手工操作

（注：程序只允许同时开一个窗口，再次启动会自动切到已打开的窗口，避免数据冲突）

service\migrate.py       旧 MySQL 数据 → SQLite 的一次性自动迁移
service\backup.py        数据备份/恢复的底层实现（复制/校验/恢复数据库文件）
assets\app.ico           程序图标（标题栏、任务栏、Alt+Tab、exe 文件图标都用它）
assets\logo.png          图标 PNG 版（.ico 读不到时的兜底）
schema.sql               建表脚本（仅旧版 MySQL 部署时用；新版 SQLite 自动建表）
db_config.json.example   切换到外部 MySQL 的配置样例
ui_config.json           外观配置（在设置面板点“应用”后自动生成，位于数据目录）
points_shortcuts.json    积分快捷键配置（在「快捷键设置」点“保存”后生成，位于数据目录）
admin.json               管理员口令哈希（首次修改口令后自动生成，位于数据目录）
dmxt_error.log           运行日志（自动生成，位于数据目录）
dist\dmxt.exe            打包后的单文件绿色版
installer.iss            Inno Setup 安装脚本（改完重新生成安装包用）
installer\全童全星上课点名系统_Setup.exe   标准安装程序（推荐给最终用户）
（数据文件 dmxt.db 及 ui_config.json / points_shortcuts.json / admin.json /
  dmxt_error.log 都在用户数据目录 %APPDATA%\全童全星上课点名系统\，不在安装目录里）
